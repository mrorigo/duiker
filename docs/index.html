Find the space you forgot.

duiker is a fast, honest disk usage analyzer for the terminal. It dives headfirst into your filesystem, maps the weight of what's there, and keeps the answer readable.

Signal over spectacle.

A focused scanner with a terminal-native interface. Fast enough for your home directory. Clear enough to act on.

01 / ACCOUNTING

Count what is there.

Allocated blocks keep sparse and virtual files from pretending they occupy your entire drive.

02 / NAVIGATION

Follow the weight.

Sort by size, filter by name, drill into directories, and keep the full path in view.

03 / CONTROL

Stay in your shell.

Readable tree output, JSON summaries, hidden-file control, depth limits, and colour that respects your terminal.

one command away

Make room for what matters.

Install from source with Cargo, then point duiker at a path. No daemon. No account. No dashboard to maintain.

# install
$ cargo install --path .

# scan one or more paths
$ duiker ~/Documents ~/Downloads

# launch the interactive view
$ duiker interactive ~
